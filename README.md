# Overlay Timer

任意のWebページの上にオーバーレイ表示できる、シンプルなカウントダウンタイマーのChrome拡張機能です。

## 特徴

- 🪟 **画面に重ねて表示** — どんなページの上でも常に最前面に表示
- 🖱️ **ドラッグで位置移動** — タイトルバー or 時刻部分をドラッグして好きな場所へ
- 🔁 **タブを切り替えても継続** — 終了時刻を保存しているので、別タブを見ていても時間は進み続けます
- 🔔 **終了時にアラーム音** — キッチンタイマー風の「ピッ、ピッ、ピッ」音が鳴り、タイマーの色が赤に変化
- ➕ **延長して再スタート** — 終了時に `+10秒` / `+1分` ボタンを押すと、その時間で即座に再カウントダウン
- ↘️ **ウィンドウ風リサイズ** — 右下隅をドラッグして幅・高さを独立に変更（時刻表示のフォントサイズも自動追従）
- 🎚️ **透明度を調整可能** — 邪魔にならないように薄くできる
- ⌨️ **直接入力対応** — 分・秒の数値を直接打ち込んで時間を設定
- ➖ **最小化モード** — 時刻だけのコンパクト表示
- ♿ **アクセシビリティ配慮** — キーボード操作・スクリーンリーダー・ハイコントラスト・モーション削減に対応

## インストール方法

1. このリポジトリをクローン or ZIPダウンロード
   ```bash
   git clone https://github.com/ozaki25/chrome-extension-timer.git
   ```
2. Chrome のアドレスバーに `chrome://extensions/` を入力して開く
3. 右上の「**デベロッパーモード**」をオンにする
4. 「**パッケージ化されていない拡張機能を読み込む**」をクリック
5. クローンしたディレクトリ（`manifest.json` がある場所）を選択

ツールバーに拡張機能アイコンが追加されたら完了です。

## 使い方

### 表示/非表示
ツールバーの拡張機能アイコンをクリックすると、現在開いているページにタイマーが表示されます。もう一度クリックすると非表示になります。

> 注: `chrome://` で始まるページや Chrome Web Store では動作しません（Chrome の制限）。

### 時間の設定

#### 直接入力
時刻表示の下にある **「分」「秒」** の数値入力欄に直接時間を打ち込めます。フォーカスを外す or Enter キーで反映されます。

#### ボタンで増減
- `-1分` / `-10秒` / `+10秒` / `+1分` ボタンで時間を増減します
- 停止中: 設定時間そのものを変更します
- 実行中: 残り時間を増減します（時間延長/短縮）

### 操作
| ボタン | 動作 |
| :--- | :--- |
| **開始 / 一時停止** | タイマーをスタート / 一時停止 |
| **リセット** | 設定時間に戻して停止 |
| **`_`** | 最小化（時刻のみ表示） |
| **`×`** | 閉じる（タイマーは裏で動作継続） |

### ドラッグ移動
タイトルバー or 時刻部分をドラッグして、好きな位置へ移動できます。位置は保存されます。

### サイズ変更
右下隅の **リサイズハンドル** をドラッグして幅・高さを独立に変更できます（通常のウィンドウのような操作感）。縦横比は固定されません。時刻表示のフォントサイズは、ウィンドウサイズに合わせて自動的に大きく / 小さくなります。
- 幅: 180px 〜 640px / 高さ: 220px 〜 640px
- キーボード操作: ハンドルにフォーカス（Tab）→ `←` / `→` で幅、`↑` / `↓` で高さを増減（`Shift` 同時押しで大きく動かす）、`Home` でデフォルトに戻す

### 透明度
下部の透明度スライダーで 50% 〜 100% の範囲で調整できます。

### タブを切り替えても継続
タイマーの終了時刻は `chrome.storage` に保存され、`chrome.alarms` により確実に終了通知が発火します。別のタブに移動したり、新しいタブを開いてアイコンを押せば、同じ状態のタイマーがそこに表示されます。

### 終了時の通知
- キッチンタイマー風の **「ピッ、ピッ、ピッ」** 音が 0.5 秒間隔で約 8 秒間鳴ります（1kHz サイン波）
- タイマー本体の背景色が赤に変化し、「終了」と表示されます（点滅はしません）
- 開始 / リセット / 延長で音は止まり、表示も元の色に戻ります
- 通知は、その時点で開いている全てのタブで発火するため、見ているタブで気付けます

### 延長して再スタート
タイマー終了時（残り 0 で停止中）に **`+10秒` / `+1分`** ボタンを押すと、その時間で即座に再カウントダウンが始まります（追加 UI なし）。
- `+1分` を押せば 1 分間で再スタート
- `+10秒` → `+1分` の順に複数押せば、合計分（例: 1分10秒）でスタート
- カスタム時間で延長したい場合は、「分・秒」入力欄に直接入力 → `開始` を押してください

> 通常時（一時停止中）に同じボタンを押した場合は、これまで通り設定時間の増減として動作します。

## アクセシビリティ

- **コントラスト**: WCAG AA 基準を満たす色を採用（白文字 × 濃色背景）
- **フォーカス表示**: すべての操作要素に黄色のフォーカスリングを表示
- **キーボード操作**: 全ボタン・入力欄・リサイズハンドルが Tab で到達可能
- **スクリーンリーダー**: `role="timer"` / `aria-live` / `aria-label` を適切に設定
- **色だけに依存しない**: 終了状態は背景色の変化に加え「終了」テキストでも明示
- **ハイコントラストモード**: Windows の `forced-colors` に対応
- **モーション削減**: `prefers-reduced-motion` を尊重しトランジションを無効化

## ファイル構成

```
chrome-extension-timer/
├── manifest.json         # 拡張機能のメタデータ
├── background.js         # アラーム管理・アイコンクリック処理
├── content.js           # オーバーレイUIとタイマーロジック
├── overlay.css          # オーバーレイのスタイル
├── icons/
│   ├── icon16.png       # ツールバー用 (16x16)
│   ├── icon48.png       # 拡張機能一覧用 (48x48)
│   └── icon128.png      # Chrome ウェブストア用 (128x128)
├── scripts/
│   └── make_icons.py    # アイコン再生成スクリプト (Pillow が必要)
└── README.md
```

### アイコンの再生成

アイコンを変更したい場合は、`scripts/make_icons.py` を編集して以下を実行してください。

```bash
pip install Pillow
python3 scripts/make_icons.py
```
