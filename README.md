# Overlay Timer

任意のWebページの上にオーバーレイ表示できる、シンプルなカウントダウンタイマーのChrome拡張機能です。

## 特徴

- 🪟 **画面に重ねて表示** — どんなページの上でも常に最前面に表示
- 🖱️ **ドラッグで位置移動** — タイトルバー or 時刻部分をドラッグして好きな場所へ
- 🔁 **タブを切り替えても継続** — 終了時刻を保存しているので、別タブを見ていても時間は進み続けます
- 🔔 **終了時にビープ音** — 3回鳴って画面も赤く点滅
- 🎚️ **サイズ・透明度を調整可能** — 邪魔にならないように小さく・薄くできる
- ➖ **最小化モード** — 時刻だけのコンパクト表示

## インストール方法

1. このリポジトリをクローン or ZIPダウンロード
   ```bash
   git clone https://github.com/ozaki25/chrome-extension-timer.git
   ```
2. Chrome のアドレスバーに `chrome://extensions/` を入力して開く
3. 右上の「**デベロッパーモード**」をオンにする
4. 「**パッケージ化されていない拡張機能を読み込む**」をクリック
5. クローンしたディレクトリ（`manifest.json` がある場所）を選択

ツールバーに拡張機能アイコンが追加されたら完了です。

## 使い方

### 表示/非表示
ツールバーの拡張機能アイコンをクリックすると、現在開いているページにタイマーが表示されます。もう一度クリックすると非表示になります。

> 注: `chrome://` で始まるページや Chrome Web Store では動作しません（Chrome の制限）。

### 時間の設定
- `-1分` / `-10秒` / `+10秒` / `+1分` ボタンで時間を増減します
- 停止中: 設定時間そのものを変更します
- 実行中: 残り時間を増減します（時間延長/短縮）

### 操作
| ボタン | 動作 |
| :--- | :--- |
| **開始 / 一時停止** | タイマーをスタート / 一時停止 |
| **リセット** | 設定時間に戻して停止 |
| **`_`** | 最小化（時刻のみ表示） |
| **`×`** | 閉じる（タイマーは裏で動作継続） |

### ドラッグ移動
タイトルバー or 時刻部分をドラッグして、好きな位置へ移動できます。位置は保存されます。

### サイズ・透明度
下部のスライダーで調整できます。
- **サイズ**: 0.5倍 〜 2倍
- **透明度**: 20% 〜 100%

### タブを切り替えても継続
タイマーの終了時刻は `chrome.storage` に保存され、`chrome.alarms` により確実に終了通知が発火します。別のタブに移動したり、新しいタブを開いてアイコンを押せば、同じ状態のタイマーがそこに表示されます。

### 終了時の通知
- ビープ音が3回鳴ります（880Hz × 2 → 1175Hz × 1）
- タイマー本体が赤く点滅します
- 通知は、その時点で開いている全てのタブで発火するため、見ているタブで気付けます

## ファイル構成

```
chrome-extension-timer/
├── manifest.json   # 拡張機能のメタデータ
├── background.js   # アラーム管理・アイコンクリック処理
├── content.js     # オーバーレイUIとタイマーロジック
├── overlay.css    # オーバーレイのスタイル
└── README.md
```
